### Project Experience

Developed and deployed a full-stack Todo Application using **Java, Spring Boot, Spring Security, JWT authentication, MySQL, JavaScript, HTML, and CSS**. Through this project, I gained practical experience in building REST APIs, implementing user authentication and authorization with JWT, connecting a Spring Boot application with a MySQL database, and handling CORS and HTTP requests between the frontend and backend. I also learned how to deploy the frontend on **Vercel** and the backend and database on **Railway**, configure production environment variables, manage application ports and database connections, and troubleshoot deployment-related issues. Additionally, I gained hands-on experience with **Git and GitHub**, resolving repository and merge issues, testing APIs using Postman, debugging frontend-backend communication, and identifying issues through browser developer tools and server logs. This project gave me practical exposure to taking an application from local development to a fully deployed production environment.

Frontend → Vercel
Backend  → Railway
Database → Railway MySQL
